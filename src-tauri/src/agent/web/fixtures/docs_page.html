Safe Fetch Client API

The safe fetch client provides defense in depth against Server-Side Request Forgery (SSRF) attacks, DNS rebinding vulnerabilities, and unbounded redirect loops by validating IP addresses before making HTTP socket connections.

Methods

The core API consists of a single asynchronous function that accepts a URL and request options, resolving DNS and verifying network destinations.

let outcome = safe_fetch("https://example.com", &opts, &cancel).await?;

All private and reserved IPv4 and IPv6 blocks are blocked by default, with loopback addresses permitted for local development servers.
